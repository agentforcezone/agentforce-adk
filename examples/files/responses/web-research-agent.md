# AgentForce ADK: Getting Started Guide

## Overview
AgentForce ADK is a comprehensive toolkit for building AI agents. It's designed to grow with your needs, starting with simple agents and scaling to complex multi-agent workflows.

## Key Features
- **Flexible Architecture**: Start simple, scale complex
- **Multi-Agent Support**: Build sophisticated agent ecosystems
- **Easy Integration**: Works with popular AI providers
- **Server Mode**: Deploy agents as HTTP APIs

1. **Installation Guide** - Set up AgentForce ADK in your project
2. **Provider Setup** - Configure AI providers (Ollama, OpenRouter)
3. **Quick Start** - Create your first agent
4. **Server Mode** - Deploy agents as HTTP APIs
